- `poll_staged_manifest_results` (`startup/staged_manifest_lifecycle.rs`) returns `()`; a commit is visible only as a local `committed`. → The reset is applied at that `committed` site (discard partial + exclude frame) rather than through a new return value; the poll runs after present and before the frame-end fold, so P-reload holds. A frontend-frame commit is harmless because frontend frames never commit.
- `FrameRateMeter` is cleared only on the vsync toggle (`main.rs` `ToggleVsync` → `frame_rate_meter.clear()`).
