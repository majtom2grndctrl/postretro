- Owner decision, 2026-10-23, round 4: **redesign the ghost limiter in this brief** (limiter v2).
  - **Why:** the corner model provably leaks.
    - Mid-grey drift: 10–31 flashes/s, unclamped, because each corner sees a slow drift while the mix swings.
    - Near-white strobes go uncounted, because the dark test assumes albedo 1.
    - A dithered fade-out can freeze.
  - **Model.** The drawn value for any albedo a and background B is d = a·p + B·q, with p = o·L and q = 1 − o (o is the presented opacity, or the coverage in dither; L is the luminance of the 8-bit drawn tint).
    - Trackers: 33 `Tracker`s at edge points (1, k/16) and (k/16, 1), k = 0..16.
    - Threshold: θ = 0.1 − 1/32 = 0.06875, for both reversal and counting, with no dark test.
    - Rate cap: one straight-line cap, max(|Δp|, |Δq|, |Δp+Δq|) ≤ 4·dt.
    - Exempt ray: the asked opacity's fall at the held L always presents, and its events share one exempt slot.
    - Window: a ghost-only window whose slots carry a u64 member mask (plus Red), a class (budgeted or exempt) and an age. An event joins the latest same-class slot if neither it nor that slot's members have counted since. A join resets the age. Red never joins.
    - Budget: a new budgeted slot needs count ≤ 4. At count ≥ 5 only the exempt ray moves. When refused, present the furthest point on the exempt-to-capped segment that needs no new slot (bisection).
  - **Proof sketch:** any interior point is s·(an edge point); a point between samples is within h/2; per-tracker events fill distinct slots; slots ≤ 6. So every (a, B) sees ≤ 3 flashes/s.
  - **Replaces:** the 3-part Strengths, resolve, two-phase decide, `keep_suppressing`, the dither shift and the dark clauses.
  - **Unchanged:** the screen path stays bit-identical; the failed-acquire restore and the public `GhostLookClamp` API stay.
  - **Tests:**
    - the fixture judges a dense (a, B) grid;
    - regression sequences: mid-grey drift, the near-white strobe at albedo 0.8, the L-shaped single change, the dither fade-out reaching 0 within 250 ms, and a tint strobe presenting ≥5 transitions/s;
    - ordinary looks are never held.
  - **Prototype:** the round-4 reviewer's `scratchpad/r4/model.py`, session-local.

The fix: draw ghosts back to front in one render pass, each a depth-only draw (no colour writes) then its colour draw (Equal). - Per-frame membership: bounded by armed links × eligible candidates. Point-in-convex tests run against the link's leaves, reusing frame-owned buffers, with no per-frame allocation. Ghost state is keyed by generation-checked id in a reused map.
- Ghost instances share the 4096 skinned palette/instance budget and drop through its existing overflow policy. Mover ghosts are a separate small list. Neither ghost pipeline binds lights, shadows or SH, so ghosts add no lighting cost.
- Per-ghost clamp: CPU-only at pack time, O(ghosts), no GPU work.
- Link replication: one small record per link per snapshot (always on, the teleporter precedent); look ramps ride only after a script set them.
- Ghost voices: capped at 16, admitted only beside an admitted real voice.
