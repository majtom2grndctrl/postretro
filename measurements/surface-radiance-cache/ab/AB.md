## Built PRLs

Already built with the `--release` after binary at HEAD 194113525: `content/dev/maps/ab-campaign-fill-{0,0.5,1}.prl` (~312 MB each) and `content/dev/maps/ab-whiteroom-fill-{0,1}.prl` (~17 MB each). `*.prl` is gitignored, so they are local only. Rebuild with:

```bash
cargo build --release -p postretro-level-compiler
measurements/surface-radiance-cache/ab/build.sh
```

(about 30 s per campaign variant, 1-2 min for the room; the first run bakes any missing `.prm` materials into `baked/`.)

## Launch

Build the engine and the tool in one profile (the tool finds its helper binaries beside itself), then from the repo root:

```bash
cargo build --release -p postretro -p postretro-tool
target/release/postretro-tool run --install-root . maps/ab-campaign-fill-0.prl
target/release/postretro-tool run --install-root . maps/ab-campaign-fill-0.5.prl
target/release/postretro-tool run --install-root . maps/ab-campaign-fill-1.prl
target/release/postretro-tool run --install-root . maps/ab-whiteroom-fill-0.prl
target/release/postretro-tool run --install-root . maps/ab-whiteroom-fill-1.prl
```

Map arguments are relative to the mod folder (`content/dev`). Not verified here: launching the windowed engine (this run had no display session). Use the same stations and `--start-pose=x,y,z,yaw,pitch` (as in `content/dev/maps/stress-warren.README.md`) for every variant so the frames compare.

## What to look at

1. Campaign-test, rooms lit only by spill from a neighbour or beyond every light's reach: fill 0 should read dark and flat there, fill 1 should carry bounced fill. Pick the intermediate that looks right.
2. Shadowed corners and under overhangs: fill should lift them, not wash out contrast.
3. Hot spots (bright patches near a light), patch-scale blotches on walls, leaks through corners.
4. Overall exposure: is fill 1 noticeably brighter than fill 0 everywhere, or only where it should be?
5. White room, fill 0 vs 1: the energy test. Fill 1 should lift the room and stay finite, no runaway brightness; the pillar's shadow side should get soft fill.
6. Entities and fog under the new id 34 (AC 39): no patch-scale blotches or new leaks on models or in fog.
