## Delegated answers
- What does "refused by name at load" do for a bad `always_active`? — The loader logs an `error!` naming the placement (`diagnostic_origin`), the key and the raw value. The NPC spawns with the archetype's value, as if the key were absent. The FGD offers only 0 and 1. Map keys are read at runtime spawn, not compiled (`ai_aggro_armed_on_spawn`, `data_archetype.rs:722`), and its sibling `enabled_on_spawn` warns and defaults. A refusal is an error, never a warning, and the bad value never takes effect. Failing the whole level load over one key would be a new class of loader failure the brief does not ask for. *Owner skim: say if you meant a failed level load.*
- Which standoff floors `tacticalRange`? — The largest `standoff_distance_for_action` over the archetype's attacks (`recursive.rs:364`), computed from the descriptor at bind. A weapon attack with no authored standoff resolves to the root `engagementRadius`, so weapon range is not consulted. The resolved standoff is what positioning uses.
- A pawn in a solid or exterior cell (no camera set), or an id 51 present with no camera sets (`has_camera_sets()` false)? — The second counts as "no id 51": every NPC is perceivable. A pawn whose cell has no camera set makes every NPC perceivable that tick. Both fall back in the safe direction, as the Decision's own fallbacks do.
- Where the per-player step lives — Sim, as a pure function of (pawn positions, the level's cell locator, id 51, AI lead, armed ghost-link couplings) → a cell bitset. It is keyed per pawn, so network relevance and VFX culling can call it later. The AI scheduler's union, NPC cell table and tiers live in sim beside it and are handed to `run_ai` through `AiTickInputs`. The binary supplies the level borrow. Nothing enters `entities`.
- Decide stagger — 15 Hz is every 4th tick. An NPC's decide phase is `mix(identity) mod 4`. Its dormant step phase is `mix(identity) mod 30`, and it decides on every 4th dormant run, keyed off its dormant run count. `mix` is a Fibonacci multiply-xorshift over the identity word.
- Fair wait for the replan budget — 6 ticks (100 ms), matching the 128-chaser row's ⌈128 / 6⌉ = 22.
