# lighting-scale--lightmap-layer-budget-gate

Brief · compact · reads: `context/lib/build_pipeline.md` §Compiler pipeline, §Build Cache · `context/lib/development_guide.md` §1.4, §Workspace · `context/lib/testing_guide.md` §Resource bounds · `context/lib/rendering_pipeline.md` §4 · read at 45c4fe5

## Problem
Developer experiment, observed defect. At 0.025 m/texel, `stress-warren-hallway-inspection` fails atlas preparation with `LayerOverflow`: its cell blocks need more bake layers than `MAX_ATLAS_LAYERS` allows. It fits at 0.027. The cap is a vestigial device floor: the runtime `max_texture_array_layers` floor from when the atlas shipped whole (`plans/done/lightmap-array-atlas`, `context/research/spatial-streaming.md`). Bake layers are now compiler working planes; no shipped section and no runtime allocation reads their count. The cap was never a memory bound, but it now bounds one by accident: the shadowmask raw fill holds every bake layer for the whole loop. When done, a named host-RAM budget bounds lightmap bake scale against the stage's predicted working set; layer count costs no memory beyond its working planes; on the cold path one copy of encoded ids 22 and 42 is live from compose through the cache write, the PRL write and its read-back; a level that cannot stream never compiles past the runtime all-resident floor; and the hallway map compiles cold at 0.025.

## Decisions
- **A budget gate replaces the layer-count cap.** After the block pack, on cold and warm paths alike, the lightmap stage's predicted working set is checked against the budget. An overage refuses before the stage bakes, naming predicted bytes, budget, packed bake-layer count and flag. This replaces the layer-count error in `plans/done/lightmap-oversize-cells-and-faces` AC [3]; the gate measures the memory that error guarded.
- **Refuse, don't coarsen.** An overage never lowers density or quality. Matches `plans/done/lighting-scale--compile-peak-ram`, whose refusal seam is where coarsening would attach, and `--sh-delta-max-size` (`build_pipeline.md`).
- **One per-stage working-set ceiling.** One flag, `--working-set-max-size` (default 16 GiB), replaces `--sh-delta-working-set-max-size` and serves both the SH-delta gate and the lightmap gate. No single stage's predicted working set may exceed it; each gate keeps its own estimator.
- **The pre-cut area check is the gate's lower bound.** Before any face is cut, a texel area no packing can undercut, times irradiance bytes (the one cost every shipped texel pays), is checked against the same budget (`research.md` §Pre-cut lower bound). Uncut charts count their padded extent; a face about to be cut counts its own polygon area, never the grid windows its polygon misses. The check fails a pathological scale region fast (pin P11), never refuses a layout the gate would admit, and carries no count of its own.
- **A map without static lights plans no lightmap placements.** Its id 22 has no blocks, so the renderer never composes its animated lightmap. Placements would produce output nothing reads and expose the map to animated-atlas refusals. A stage that bakes nothing predicts zero and is never refused.
- **The shadowmask fill is released per bake layer.** Live raw fill is one bake layer plus the cell blocks of cuts still open. Encoded sections stay byte-identical; the predicted shadowmask term follows the new lifetime.
- **One encoded section copy on the cold path.** Ids 22 and 42 stream into the cache and the PRL file, and the PRL read-back checks them streamed (`plans/done/lighting-scale--shadowmask-cold-working-set`; `development_guide.md` §1.4). Entry and file bytes do not change; the predicted sections term counts one copy. A warm memo hit may hold the cache payload beside the parsed section, unpriced: the cold build is the ship source of truth, and warm iteration may approximate (`development_guide.md` §1.4).
- **Past the runtime all-resident floor: refuse what cannot stream, warn what can.** A level with blocks streams only with a usable id 51 and usable portals (`rendering_pipeline.md` §4). The compiler emits id 51 exactly when the loader's portal test passes, so it knows which levels must load all-resident. Such a level past the floor is refused by name, since every machine would render placeholder lightmaps. A level that can stream gets a named warning, since only `POSTRETRO_LIGHTMAP_STREAMING=all-resident` reaches the floor. One constant names the floor for the check and the residency dry run.
- **One all-resident placement, below both consumers.** The compiler's check must count exactly what the renderer's counts, so both call one placement in a crate both already depend on. Rival: a normal `postretro-render-cpu` edge from the compiler. It fails on layering and rebuild coupling: `level-compiler` would sit above `render-cpu`, and every change at the `entities` chokepoint would rebuild `prl-build` (`development_guide.md` §Workspace).
- **Layer placement:** compiler, mechanism. No PRL format or loader change. Rendering is unchanged; the all-resident placement only moves crates.
- **Output change:** only maps without static lights. They lose placements and animated chunks they never rendered. Today such a map keeps placements unless a chart exceeds the pool edge, its block count exceeds the vertex limit, or its pack overflows the cap. For one that ships animated chunks today, the renderer's no-static-blocks warning stops firing and the lightmap memory meter's animated rows read Dummy instead of Fallback.
- Non-goal: refusing before the SH light stages. They precede atlas preparation (`build_pipeline.md` §Compiler pipeline). Moving the pack ahead of them saves only the first cold build, since warm reruns reuse SH (`research.md` §Measured). Follow-up for modders' first bake.
- Non-goal: a whole-process RSS bound. Earlier stages' outputs stay resident, and no resident-baseline term is measured.
- Non-goal: shrinking the remaining terms (one encoded copy per section, the per-layer plane, face map and partition window). The gate prices them.
- Non-goal: skipping cache entries for empty (layer, light) pairs. Separate direct build (`research.md` §Cache density).
- Non-goal: changing the 0.04 default density. Runtime residency tiers must be re-measured first (`plans/large-map-spatial-residency.md`, Low tier).
- Non-goal: other whole-map ceilings. Non-streamed GPU resources belong to the large-map-spatial-residency seed; crash and silent-limit cases go to a separate sweep (`research.md` §Scale-ceiling inventory).

## Path
- First slice: per-layer fill with the cut-face carry, the riskiest step for byte identity. The walk is already layer-major: uncut faces finish when their layer's last light is consumed; a cut face carries its sub-faces' cross-layer state until the last layer it touches closes (`research.md` §Shadowmask fill lifetime). Seams: `shadowmask_bake.rs::allocate_shadowmask_raw_fill`, `shadowmask_bake/fill.rs::OwnershipFill::finish`, `LayerFaceMap`, `encode.rs::encode_blocks_bc5`. `RAW_FILL_LIVE_BYTES` is thread-local and holds a current value; the peak rows need a cross-worker peak counter.
- Rival to the carry: co-locate a cut's sub-faces on one bake layer. Fails: each sub-face block can fill a pool edge.
- Gate seam: `pipeline/lightmap_stage/peak.rs::predicted_peak`, a pure function of `PreparedAtlas`. Precedent: `pipeline.rs::gate_delta_working_set` and its tests; estimator strictness differs (`research.md` §Existing gates). The gate replaces `MAX_ATLAS_LAYERS` in `block_layout.rs::pack_cell_blocks_within`; the lower bound replaces it in `atlas_layout.rs::check_planned_area`, with budget and irradiance mode threaded into `plan_cut_charts`. `pack_cut_charts`'s no-static-light branch returns unplaced charts unconditionally. The constant goes. The old flag's call sites, CLI contract tests and `build_pipeline.md` row move in the same change; no `docs/` page names it.
- Streamed writes (`research.md` §Section copies at the cache write): id 22's `cache.put` in `pipeline/lightmap_stage.rs` becomes `cache.rs::put_streamed`, after `shadowmask_bake/memo.rs::cache_shadowmask_section`. `pack/section_plan.rs` plans ids 22 and 42 as `to_bytes()` closures; `pack_output.rs::PlannedSection::with_writer` streams, after `pack/cluster_sh_payloads.rs`. `pack_output/readback.rs::validate_readback` reads every section but id 50 whole; `validate_cluster_sh_payloads_readback` is the streamed precedent.
- Pool-layer check seam: after the CellResidencySet stage, before `lightmap_stage::bake_fused_prepared`. Reads whether `cell_residency_bake::cell_residency_set_bake_cached` returned a section, plus block extents and alignment. Placement move options: `research.md` §Runtime pool-layer count at compile time. Move the placement in its own behavior-preserving commit.
- `pipeline.rs` and `main.rs` are past 800 lines. Add the gate beside the delta gate without growing them, or extract first in its own commit.
