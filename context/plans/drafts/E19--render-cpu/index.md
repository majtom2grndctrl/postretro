# postretro-render-cpu

> Epic: `E19--render-stack-decomposition`. The CPU harvest — the largest direct compile-time win — and the cut that severs the `scripting → render` dependency.

## Goal

Move the CPU islands embedded in GPU files (byte-packing, frame planning, validation) — plus the already-CPU `fx` data modules that move whole — and their no-GPU test suites into a CPU-only crate, so they recompile off the wgpu path and so `scripting/systems/*` depend on shared CPU data instead of the renderer.

## Scope

### In scope
- `postretro-render-cpu`: move the wgpu-free render data/logic —
  - `frame_uniforms.rs` (`FrameUniforms`, `build_uniform_data`, `UNIFORM_SIZE`, `SDF_SHADOW_FLAG_ATLAS_PRESENT`, `LightingIsolation`/`SdfShadowMode`/`DynamicDirectIsolation`),
  - `mesh_instances.rs` (`plan_mesh_frame`, `MeshInstanceInput`, `PlannedInstance`, `ModelDrawGroup`, `MeshFramePlan`, `JointCounts`, `MAX_PALETTE_ENTRIES`, `MAX_INSTANCES`),
  - the mesh-data surface `scripting` imports — `mesh_visible` (fn) and `ClipMetadata` (carved out of `mesh_pass.rs`),
  - the SH scripted-light animation constants `scripting/systems/light_bridge.rs` imports (`ANIMATION_DESCRIPTOR_SIZE`, `SCRIPTED_BRIGHTNESS_SLOT`, `SCRIPTED_COLOR_SLOT_F32`, `SCRIPTED_FLOATS_PER_LIGHT` — carved out of `sh_volume.rs`),
  - `material_plan.rs` CPU half (`plan_submesh_materials`, `build_material_uniform`, `parse_blake3_key`, `resolve_model_open_path_and_handle`),
  - `fog_mask.rs` (`compute_fog_cell_mask`, `sphere_intersects_any_fog_aabb`),
  - `crate::fx::{smoke,fog_volume}` — top-level `src/fx/`, already wgpu-free, so these move whole (not a carve; distinct from the GPU `render/smoke.rs`): `SpriteFrame`, `load_collection_frames`, `SPRITE_INSTANCE_SIZE`, `MAX_SPRITES`, `FogVolume`, `FogPointLight`, `MAX_FOG_POINT_LIGHTS`, packing constants,
  - `src/lighting/chunk_list.rs` (a sibling of `render/`, not under it) (`ChunkGrid`, `CHUNK_GRID_UNIFORM_SIZE`) and tests,
  - the per-function-ruled CPU halves of `loaded_texture` (`.prm` parse/slot-plan/mip math), `sdf_atlas`, `sdf_shadow`, `sh_volume`, `sh_compose`, `animated_lightmap`, `screen_effects::pack_effect_uniform`,
  - their no-GPU unit tests, including the WGSL byte-layout guards (the `group3_shader_bindings_are_represented_by_rust_layout` guard fn in `sh_volume.rs`, plus the `uniform_tests` and `shader_tests` modules) — the assertions pinning moved packers relocate with them; any covering renderer-side layouts stay.
- **WGSL binding-index/stride constants travel with their packers** (no shader-layout drift).
- Re-point `scripting/systems/{mesh_render,mesh_anim,light_bridge,emitter_bridge,particle_render,fog_volume_bridge}.rs` to `postretro-render-cpu`.
- Depend on `postretro-level-loader`, `postretro-level-format` (`ChunkLightListSection`), `postretro-visibility` (for `VisibleCells`, used by `mesh_visible`), `postretro-render-data`, `postretro-entities` (`SlotValue`, used by `pack_effect_uniform`), `postretro-model` (`gltf_loader::Submesh` plus crate-root `ModelHandle` and `sample_params::{CaptureInstruction,MeshSampleParams}`, used by `material_plan`/`mesh_instances`), `postretro-lighting` (`light_space_matrix` — the CPU light-space `Mat4` helper the descended mesh cone-cull tests call, carved out of `spot_shadow.rs` into `postretro-lighting`; see Task 1 — a **dev-dependency**, since those consumers are `#[cfg(test)]`), `glam`, `bytemuck`. (This adds a `render-cpu → model` edge not yet drawn in the epic hub crate graph — amend the hub graph at promotion.)

### Out of scope
- Anything that reads `FullRenderer` fields or owns wgpu resources — stays in `postretro-renderer`.
- The GPU passes themselves (`mesh_pass` GPU half, `sh_volume` GPU compose, `fog_pass`, `smoke` GPU, `sdf_*` passes, `spot_shadow`'s `SpotShadowPool`).
- `splash::load_splash` — although wgpu-free, it returns `postretro_ui::UiTexture` and takes the binary-side `crate::startup::SplashSource`, so moving it would add a `render-cpu → postretro-ui` edge absent from the epic's crate graph for no compile-time win. Stays binary-side (or is `E19--ui`/`postretro-ui` territory), not this crate.

## Acceptance criteria
Inherits the epic global acceptance criteria — see `E19--render-stack-decomposition/index.md`. Durable decisions are captured into `context/lib/` per spec as each spec is approved — not in one batch at first promotion.
- [ ] Crate is a workspace member; `cargo build --workspace` + `cargo test --workspace` pass; all moved packing/planning/validation tests pass from their relocated home.
- [ ] `cargo tree -p postretro-render-cpu` shows no `wgpu`/`winit`/`glyphon`/`kira`. (Manual/CI gate, not a `cargo test` assertion.)
- [ ] **No `scripting/systems → render`/`fx`-data edge remains:** both `rg "crate::render" crates/postretro/src/scripting` and `rg "crate::fx::(smoke|fog_volume)" crates/postretro/src/scripting` return nothing — grep *without* the `use ` prefix so inline fully-qualified paths and rustdoc links count too (e.g. `mesh_anim.rs`'s `crate::render::mesh_pass::ClipMetadata` refs must be re-pointed, not just `use` lines). All six re-pointed bridges (`mesh_render`, `mesh_anim`, `light_bridge`, `emitter_bridge`, `particle_render`, `fog_volume_bridge`) import `postretro-render-cpu` instead. (`scripting/reactions/*` legitimately keep other `crate::fx` primitive imports — those primitives stay renderer-side.) A future `postretro-scripting-core`/scripting layer never depends on `postretro-renderer`. (Grep/review gate, not a runnable test.)
- [ ] WGSL byte-layout guards (the `group3_shader_bindings_are_represented_by_rust_layout` guard fn in `sh_volume.rs`, plus the `uniform_tests` and `shader_tests` modules) pass — moved packers produce identical bytes.
- [ ] Editing `postretro-render-cpu` does not recompile `wgpu`/`naga`. (Manual/CI gate.)

## Tasks

### Task 1: Rule, carve, and extract `postretro-render-cpu`
One atomic task — the membership ruling and the move are the same agent's job: the ruling *is* the move-plan, and most descending modules need no source change, so a separate extractor could not recover the move-list from the tree. Do the ruling (Step A) and the extraction (Step B) in one pass.

**Step A — rule.** Apply the descent rule against current source: a helper leaves if it is wgpu-free **and** does not read `FullRenderer` state; WGSL binding constants travel with their packers. The ruling below was produced by reading current source; carve the SPLIT files along their seam first (these are oversized — `mesh_pass.rs` 3544, `sh_volume.rs` 2443 — split, don't transplant whole).

**Membership ruling (source-confirmed).** Where this ruling and the Scope sketch above differ, this source-confirmed enumeration is authoritative. Everything in the candidate surface descends except the GPU-recording halves of two files, which split:

- **DESCEND** (wgpu-free, no `FullRenderer` read; for mixed files, only the parenthesized items descend — the rest of the file stays renderer-side): `frame_uniforms.rs` (`FrameUniforms`, `build_uniform_data`, `UNIFORM_SIZE`, `SDF_SHADOW_FLAG_ATLAS_PRESENT`, the three isolation enums); `mesh_instances.rs` whole (`plan_mesh_frame`, `MeshInstanceInput`, `PlannedInstance`, `ModelDrawGroup`, `MeshFramePlan`, `JointCounts`, `instance_casts_into_cone`, `MAX_PALETTE_ENTRIES`, `MAX_INSTANCES`); `material_plan.rs` CPU set (`plan_submesh_materials`, `SubmeshMaterialPlan`, `build_material_uniform`, `parse_blake3_key`, `resolve_model_open_path_and_handle`); `fog_mask.rs` whole; `src/lighting/chunk_list.rs` (`ChunkGrid`, `CHUNK_GRID_UNIFORM_SIZE`); `screen_effects.rs` (`pack_effect_uniform`, `EffectUniform`); the CPU packers in `sh_volume.rs` (`build_grid_info_bytes`, `build_animation_buffers`, `build_dynamic_direct_params_bytes`, the f16 codec, the scripted-light animation constants `light_bridge` imports), `sh_compose.rs` (`build_delta_buffers`, `DeltaComposeBuffers`, `f16_bits_to_f32`), `sdf_atlas.rs` (`build_meta_bytes`, `scatter_bricks_to_atlas`), `sdf_shadow.rs` (`pack_params_bytes`, `SdfShadowTuning`), `animated_lightmap.rs` (`validate_cross_section`, `AnimatedLmDebugConfig`); and `fx::{smoke,fog_volume}` data.
- **SPLIT `mesh_pass.rs`:** carve the pure-CPU `mesh_visible` (`:1919`) + `mesh_visible_in_cell` (`:1933`) — a `LevelWorld`+`VisibleCells` cell-membership predicate, the surface `scripting/systems/mesh_render.rs` imports — and `ClipMetadata` into the CPU crate; leave the GPU draw-recording renderer-side. (`mesh_visible` is pure, not GPU — it carries the `postretro-visibility` dep noted above.)
- **SPLIT `loaded_texture.rs`:** carve the CPU `.prm` parse / mip / slot-plan (`level_byte_size`, `slot_levels`, `header_mip_count`, `texture_slot_plan`); leave `upload_texture_data` (`Device`/`Queue`) renderer-side.
- **SH pair caveat:** `sh_volume.rs` and `sh_compose.rs` are both mixed files that mutually import (`sh_volume` → `sh_compose::f16_bits_to_f32`; `sh_compose` → `sh_volume::{AnimatedLightBuffers, f32_to_f16_bits, …}`) — carve them as a pair in one pass: the CPU packers descend together and the two surviving GPU halves both re-import them from `postretro-render-cpu`. This is the hardest carve; do it deliberately.
- **SPLIT `src/lighting/spot_shadow.rs`:** carve **only** the pure-CPU `light_space_matrix` (`:20`, `&MapLight -> Mat4`, glam-only) **into `postretro-lighting`** (not this crate) — it is lighting math several crates call: the descended `mesh_instances` cone-cull tests, plus `shadow_cull.rs` and `render/renderer_light_slots.rs`. `postretro-lighting` already depends on `postretro-level-loader` (for `MapLight`) and already backs `spot_shadow.rs` (`pub use postretro_lighting::NO_SHADOW_SLOT`), so this adds **no new edge**, and both `render-cpu` and `postretro-renderer` reach the helper with no `renderer → render-cpu` edge. Re-point its callers to the new home. Everything else in the file — `assign_ranked_slots` and the `SpotShadowPool` GPU pool (`SHADOW_DEPTH_FORMAT` onward, `:91`+) — stays renderer-side for `E19--renderer-gpu` (Decision 7). (The cone-frustum helpers those tests pair it with — `cone_frustum_planes`/`cone_enclosing_aabb` — already live in `postretro-render-data` per Decision 9; nothing to move there.)
- **Travelling WGSL constants** (move with their packers, never alone): `UNIFORM_SIZE`, `MATERIAL_UNIFORM_SIZE`, `SH_GRID_INFO_SIZE`, `SHADOW_PASS_PARAMS_SIZE`, `SDF_ATLAS_META_SIZE`, `DYNAMIC_DIRECT_PARAMS_SIZE`, `CHUNK_GRID_UNIFORM_SIZE`.

**Step B — extract.** Create `postretro-render-cpu` as a workspace member. Move every DESCEND item plus its travelling WGSL constants and its no-GPU tests into the crate, and perform the SPLITs above; bump each moved item's visibility to `pub` as the cross-crate move requires (most are `pub(crate)`/`pub(super)` today — `cargo build` surfaces each). Re-point **all** call sites of the moved modules, not just scripting: the six `scripting/systems` bridges (`mesh_render`, `mesh_anim`, `light_bridge`, `emitter_bridge`, `particle_render`, `fog_volume_bridge`) **and** every renderer/binary importer that `cargo build --workspace` flags (expect ~9 files, incl. `render/{mod,smoke,fog_pass,mesh_pass,renderer_lighting,renderer_full_init}.rs` and `startup/lifecycle.rs`). Carve `light_space_matrix` into `postretro-lighting` first (Step A's `spot_shadow` split) so the moved tests compile. Wire deps: `postretro-level-loader`, `postretro-level-format`, `postretro-visibility`, `postretro-render-data`, `postretro-entities`, `postretro-model`, `glam`, `bytemuck`, and `postretro-lighting` as a `[dev-dependencies]` entry (its only render-cpu consumers are `#[cfg(test)]`); full justifications in Scope.
