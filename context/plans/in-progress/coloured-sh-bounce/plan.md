## Performance and lifetime
- Runtime only adds scalar multiplies and updates existing fixed-size uniforms; no new allocations, sampled bindings or GPU buffers.
- Stats are one fixed-size record per interned texture; compute in fixed texel order while one texture is live. Do not persist stats.
- SH retains bounded tracing and per-light cache policy; colour adds a per-hit lookup and multiply offline.
- Material stage runs once for existing world/mover names; late stage only adds fluid-only names, then model/sprite bundles, flushing one byte report.
