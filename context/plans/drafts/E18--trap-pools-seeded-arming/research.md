## Decisions carried into the spec (with rationale)

- **Members are trigger volumes only.** E18-C authoring legitimately shares tags between a trigger
  and its spawner payload; warning on non-trigger tag-sharers would be noise. Membership is
  defined, not filtered-with-warning.
- **Pass force-sets both selected and unselected members.** Makes the roll outcome independent of
  authored `enabled_on_spawn` (warn on `true` as an authoring smell) — no half-armed states leak.
- **Before `levelLoad`, not in the after-install host block.** Script overrides fired by
  `levelLoad` reactions must deterministically win over the roll; the :789-793 host block runs
  after `install_world_cpu` returns, too late for that ordering.
- **One PRNG stream across pools** (vs per-pool derived seeds): simpler, deterministic given
  composed declaration order; per-pool independence has no driving use case (declaration order is
  already load-bearing for the overlap rule).
- **Headless no-seed = arm-all bypass** (human decision, replacing the earlier fixed-seed-`0`
  draft). Both are byte-identical, but a fixed seed bakes a seed-and-declaration-order-dependent
  subset into every unpinned batch run; arm-all is order-independent and exercises every authored
  trap. Determinism ACs that assert an exact subset all pin an explicit seed, so none depended on
  the old default.
- **`arm: 0` valid-and-silent** (human decision, closing the open question): an all-traps-off
  configuration, recorded by the install report. Runtime pool/story-event arming is foreshadowed
  in Out of scope — the per-trigger `armTrigger` composition after the roll is already the
  substrate.
- **`arm` XOR `armFraction`, both tiers.** A mod-global pool spans levels with differing member
  counts and `setupLevel`'s `world.query` never runs at mod scope, so a proportion form is
  required there; keeping both forms valid at both tiers gives one descriptor shape and one
  validation path. Two explicit fields over one polymorphic `arm` — values below 1 silently
  flipping semantics is a footgun. Fraction resolves per install as `floor(fraction × members)`:
  one correctly-rounded f64 multiply then floor, bit-identical cross-platform, no PRNG.
- **Cross-tier same-tag = replace, not merge.** Two pools rolling one tag would force two
  arm/disarm passes over the same member set with declaration distance deciding the outcome; one
  declaration per tag per level, level-local wins (the override idiom, logged at info). Within a
  tier the draft's first-wins duplicate-skip stays.
